# Roadmap

V2 sonrasında genişletilebilecek başlıklar:

- Kurumsal SSO/OIDC ve rol tabanlı yetkilendirme
- Sunucu tarafı güvenli WMS/WFS proxy/token broker
- OGC API Features, WMTS, WCS ve 3D Tiles adaptörleri
- Mekânsal filtre/sorgu oluşturucu
- Katman sıralama ve özel çalışma alanı profilleri
- Baskı/PDF raporları ve veri dışa aktarma
- İzleme/telemetri ve servis SLA panosu
- Kurumsal bookmark, proje paylaşımı ve ekip oturumları

Bu başlıklar mevcut V2 mimarisini değiştirmeden modüler olarak eklenebilir.
