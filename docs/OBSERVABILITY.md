# Observability

Üretim ortamında önerilen sinyaller: uygulama başlatma süresi, SceneView hazır olma süresi, servis yükleme başarısı/latency, layer load error oranı, WebGL context kaybı, kullanıcı cihaz performans profili ve kritik istemci hataları.

Telemetri eklenirse kişisel veri toplamadan, açık veri sözleşmesi ve örnekleme politikasıyla uygulanmalıdır.
