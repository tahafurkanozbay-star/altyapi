# Project Structure

- `src/App.tsx`: uygulama kabuğu ve ana durum akışı
- `src/gis/`: ArcGIS runtime ve layer adaptörleri
- `src/components/`: arayüz bileşenleri
- `src/lib/`: katalog, performans, URL state ve storage yardımcıları
- `public/`: servis kataloğu, manifest ve service worker
- `tests/`: saf mantık testleri
- `.github/`: CI, Pages, güvenlik ve dependency otomasyonu
